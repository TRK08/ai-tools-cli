# 005. Пять агентов, глобальная область и интерактив

## Цель и входные условия

После аппрува 004 поддержать все пять агентов, две независимые области и выбор агентов при `add` без `-a`. Точная таблица путей и CLI-правила находятся в [SPEC.md](SPEC.md).

Исходные примеры: `../../../skills/src/agents.ts`, promptForAgents в `../../../skills/src/add.ts` и `../../../skills/src/add-prompt.test.ts`. Не переносить весь каталог агентов, обязательные universal-агенты, историю выбора и auto-detect.

## Работы

1. Добавить таблицу Claude Code, Codex, OpenCode, Pi и Cursor с локальными/глобальными путями. Локально Codex/OpenCode/Cursor читают `.agents/skills` напрямую, ссылки нужны Claude Code/Pi. Глобальная общая копия — `~/.agents/skills`, lock — `~/.agents/skills-installer-lock.json`; пути агентов и env — из SPEC. Учитывать CLAUDE_CONFIG_DIR и XDG_CONFIG_HOME.
2. Добавить повторяемый `-a`/`--agent` и `-g`/`--global` в управление установками. Проверять имена и объединять повторения до файловых изменений.
3. Реализовать на Clack выбор всех пяти агентов при отсутствии `-a`: отмечены Claude Code, OpenCode, Codex; Cursor и Pi не отмечены. Показывать пути назначения выбранной области.
4. Любую отметку можно снять, но подтвердить пустой выбор нельзя. Стрелки/пробел/Enter, отмена без побочных эффектов; код отмены 0.
5. Явный `-a` полностью обходит меню. Если stdin или stdout не TTY и `-a` отсутствует — код 1, инструкция задать агентов; не выбирать автоматически и не ожидать ввода бесконечно.
6. Выбор завершать до подготовки/скачивания/создания каталогов установки. Историю предпочтений не сохранять. `--force` не отключает меню.
7. Повторный add объединяет выбранные успешные подключения с существующими. Не выбранный в новом меню прежний агент остаётся подключённым.
8. При частичном успехе сохранять успешные подключения и код 1. Если ни одно запрошенное подключение не удалось — прежние файлы/lock остаются, новая неиспользуемая копия удаляется.
9. Remove с `-a` удаляет выбранные подключения; без `-a` — все. Прямое подключение снимается из записи, но общая копия остаётся до последнего зарегистрированного агента. Ссылки удаляются отдельно. Ручные правки не защищать; чужие назначения не удалять. Снятие прямого подключения не гарантирует исчезновение видимости скилла у агента.
10. List поддерживает область и фильтр агентов, выводит имя, версию, политику и агентов. Список агентов в проектном lock общий для проекта.
11. Обновить README, Changeset и демонстрационные примеры.

## Критерии готовности

- [x] В каждой области пять агентов подключаются к одной общей копии.
- [x] Локальная и глобальная установка одного имени независимы.
- [x] Add без `-a` показывает меню с фиксированным предвыбором; с `-a` меню отсутствует.
- [x] Отмена и отсутствие TTY не меняют установку или lock и не получают источник.
- [x] Повторное добавление не удаляет прежние подключения и не дублирует записи.
- [x] Сбой подключения всех выбранных агентов не обновляет существующую установку.
- [x] Частичное удаление сохраняет копию; последнее удаляет её, включая ручные правки.

## Проверки

- Общие проверки из индекса; каждый агент отдельно и несколько вместе в двух областях.
- Точные пути и env-переопределения на изолированных корнях.
- Clack с управляемыми потоками/TTY: предвыбор, переключение, пустой выбор, подтверждение, Escape/Ctrl+C. Не ограничиваться проверкой аргументов мок-функции: проверить возвращённый выбор и дальнейший результат установки.
- Отдельный CLI-процесс без TTY: ошибка без `-a`, успех с явным агентом.
- Повторяющийся/неизвестный агент, повторный add существующей записи, отсутствие удаления после снятия отметки.
- Существующий demo v1 для Codex; попытка замены и подключения Claude Code с чужим назначением — Codex остаётся на старом содержимом, lock прежний.
- Codex/OpenCode/Cursor одновременно используют один путь без ссылок на себя; lock допускает общий путь прямых подключений. Отсутствующий `.agents/skills/<name>` не считается успешным прямым подключением.
- Смесь успешных/ошибочных подключений, отказ всех новых подключений, удаление одного и последнего.

### Изменения

- `src/installer/agents.ts`: таблица пяти агентов, точные проектные и глобальные
  пути, проверка/объединение повторов, trimmed `CLAUDE_CONFIG_DIR` и `XDG_CONFIG_HOME`
  с default для пустых значений. Проектные пути от env не зависят.
- `src/cli/agents-prompt.ts`: Clack multiselect с фиксированными defaults,
  подсказками путей выбранной области и подменяемыми потоками. Отмена и отсутствие
  TTY завершаются до запуска Installer; явный `-a` обходит меню, force его сохраняет.
- `src/cli/program.ts`: повторяемый `-a` и `-g` у add/list/remove. List показывает
  имя, версию, политику и всех агентов выбранных записей. Partial/failed
  дают код 1 и ошибки по агентам; отмена даёт код 0.
- `src/installer/local.ts`: независимые области, объединение успешных подключений
  с прежними, прямые подключения и относительные проектные ссылки. Для существующих
  подключений используются сохранённые пути даже после смены env.
- Отказ всех выбранных подключений сохраняет прежние copy и lock, в том числе
  при отказе создания ссылок после замены; новая неиспользуемая копия удаляется.
  Частичный успех фиксируется; новая общая версия доступна всем прежним агентам.
- Remove снимает выбранные подключения, сохраняет copy до последнего агента,
  затем удаляет её вместе с ручными правками. Чужие объекты сохраняются с ошибкой;
  успешные удаления других агентов фиксируются. `src/installer/filesystem.ts`
  откатывает созданные/снятые ссылки вместе с copy при ошибке lock.
- Добавлены `tests/agents-installer.test.ts`, `tests/agents-prompt.test.ts`, обновлены
  `tests/lifecycle-cli.test.ts`. Обновлены README, `docs/architecture.md`,
  `docs/installer.md`, `demo/README.md` и Changeset. Зависимости/package-lock,
  соседние проекты и существующие рабочие установки не изменялись.

не получается, HTTP не вызывается. Отдельные процессы CLI без TTY дают код 1
без `-a` и код 0 с явными агентами.

### Ограничения

- Пропущен прежний тест 003 `preserves resource names that are not valid UTF-8`:
  такие имена нельзя создать на APFS. Новый цикл на Linux и runtime Node 22.20
  в этом запуске не проверялись; платформенная матрица относится к 011.
- Проверены назначения и читаемость файлов в изолированных корнях. Обнаружение
  скиллов настоящими приложениями пяти агентов не запускалось; финальная проверка
  обнаружения относится к 011.
- Родители назначений должны быть обычными каталогами. Env-пути внутри общей
  папки skills отвергаются, чтобы не создать циклическую ссылку внутри копии.
  После отказа могут остаться пустые родительские каталоги; copy/lock откатываются.
- Снятие прямого подключения не скрывает copy от агента, пока остаются другие
  зарегистрированные подключения. Crash journal остаётся вне MVP.
- Задачи 006–011, публикация npm, push и автоматический коммит не выполнялись.
