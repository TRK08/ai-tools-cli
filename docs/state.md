# Состояние установки

Единственная схема lock `version: 1` содержит массив `packages`. У каждого пакета есть `slug`, постоянный
`registryUrl`, одна `version` и массив установленных `skills`. Запись скилла
хранит имя компонента `name`, `installName`, SHA-256 ZIP `archiveHash`, хеш
установленного дерева `contentHash` и `connections` с агентом, путём и видом.

Проектный lock находится в текущем каталоге, глобальный — в `~/.agents/`.
Пути подключений в проекте относительные и используют `/`. Глобальные пути
абсолютные. Прямые подключения нескольких агентов могут указывать на одну
общую копию. Имена установок и физические назначения разных записей уникальны.

Lock читается как обычный файл с проверкой идентичности и размера. Запись выполняется
через собственный временный файл, fsync и rename под блокировкой области.
Файловые операции Installer и новый lock применяются в одной транзакции на пакет.
Валидатор проверяет только эту структуру и её инварианты. Неизвестные поля,
неверные типы, повторяющиеся пакеты/имена/агенты и пересекающиеся назначения — ошибки.
Подключения имеют только виды `direct/link`. Чужие каталоги под управление не принимаются.

## Хеш содержимого

Хеш дерева учитывает типы, логические пути и исходные байты. Права и пустые ветви
игнорируются. Unicode-имена для расчёта нормализуются в NFC. На диске остаются
исходные имена. Хеш относится к общей копии. Хранилище дополнительно сверяет descriptor, состав
файлов, их размеры, SHA-256 и executable bits на POSIX.

## Перенос проекта через Git

Коммитьте `skills-installer-lock.json`, `.agents/skills/` и `.claude/skills/`
вместе. `.agents/skills/<installName>` содержит обычные файлы, а
`.claude/skills/<installName>` — ссылку `../../.agents/skills/<installName>`.
В индексе Git ссылка должна иметь режим `120000`; её цель относительна.
Правила attributes для ресурсов `.agents` должны сохранять байты, включая
бинарные данные и окончания строк. Используйте [пример проекта](../.gitattributes).
Не исключайте вложенные файлы скиллов через ignore. Служебные файлы и каталоги
добавьте в ignore.

```gitignore
.agents/.skills-installer-work-*/
.skills-installer-operation.lock
.skills-installer-lock-*.tmp
```

После корректного clone ссылка сразу читает `.agents` нового checkout без установки.
На Windows нужны разрешение ОС на создание symlink и `core.symlinks=true` при
checkout. При `core.symlinks=false` Git создаёт обычный файл с текстом цели.
[Документация Git](https://git-scm.com/docs/git-config#Documentation/git-config.txt-coresymlinks)
CLI не выполняет git add, commit и изменение пользовательской Git-конфигурации.

После clone `list` и `remove` используют сохранённые пути в новом рабочем каталоге.
Для update требуется доступ к реестру, указанному в lock.
