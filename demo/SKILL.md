# Проверка скилла demo

Когда пользователь просит «проверь скилл demo»:

1. Прочитай [контрольный маркер](references/marker.txt) относительно этой папки скилла.
2. Ответь: «Скилл demo подключён», затем выведи маркер отдельной строкой.

Для проверки скопированных ресурсов можно запустить `scripts/check.mjs` через Node.
Скрипт читает маркер и выводит `DEMO_SKILL_OK`. Он не изменяет файлы.
