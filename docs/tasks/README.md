## Цикл одной задачи

1. Прочитать SPEC, стек и текущую задачу; проверить пользовательский аппрув зависимостей.
   Первый старт разработки требует отдельного поручения.
2. Отметить in_progress в задаче и индексе; выполнять одну задачу реализации за раз.
3. Реализовать её объём, выполнить общие и указанные в задаче проверки.
4. Записать фактические результаты, ручные проверки и ограничения; пропуски обозначить явно.
5. Перевести в in_review, показать результат и остановиться до ответа пользователя.
6. Замечания отработать со статусом changes_requested и повторить затронутые проверки.
7. Только явный аппрув проверенного результата даёт approved: записать дату и цитату,
   синхронизировать индекс. Затем можно перейти дальше, если пользователь не попросил остановиться.

Зелёные тесты, согласование плана и истечение времени не заменяют аппрув.
Невыполненная проверка требует завершения либо явного пользовательского исключения.
Коммиты, push и публикация не выполняются автоматически.

## Статусы

planned — не начата; in_progress — выполняется; in_review — ожидает аппрува;
changes_requested — требует доработки; blocked — есть описанное препятствие;
approved — результат явно одобрен; excluded — исключена пользователем.
Источник статуса — метаданные файла задачи, индекс синхронизируется с ними.

## Общие проверки перед ревью реализации

```sh
npm run type-check
npm run lint
npm run format:check
npm run test:run
npm run build
npm run package:check
```

Использовать npm, фиксировать зависимости в package-lock.json, в CI — `npm ci`.
Проверки не должны исправлять файлы. Дополнительно проверить diff и сценарии задачи.
Для правок только документации достаточно проверки содержания, ссылок и согласованности.
Если ОС, backend или агент недоступны, это ограничение проверки, а не успешный результат.

## Что показывать на ревью

Реализованный сценарий, изменённые файлы, команды воспроизведения, фактические проверки
с датой/средой, известные ограничения и ссылку на текущую задачу in_review.
Changesets описывает изменения, но не заменяет аппрув и не запускает релиз.
