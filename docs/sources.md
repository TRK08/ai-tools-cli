# Подготовка источников

Адаптер возвращает [PreparedSource](../src/sources/types.ts): `directory`, имя/описание,
постоянную `identity`, версию, хеши и `cleanup()`. Он не знает об агентах и не пишет lock.
Все корни передаются явно. Прямой потребитель вызывает cleanup в finally; Installer
очищает workspace операции целиком.

| Адаптер                 | Вход и результат                                                                       |
| ----------------------- | -------------------------------------------------------------------------------------- |
| `prepareDirectory`      | Папка → снимок с разыменованными ссылками; version=null                                |
| `prepareArchive`        | Локальный .tar.gz/.tgz → снимок и archiveHash; version=null                            |
| `prepareRegistrySource` | RegistryReference + клиент → проверенный архив, фактическая версия и registry identity |

`prepareLocalSource` выбирает папку/архив. Существующий локальный путь имеет приоритет
перед registry slug; папка с расширением `.tgz` остаётся папкой. Явные пути и архивные
суффиксы не превращаются в registry при отсутствии файла.

## SKILL.md и локальная папка

В корне нужен `SKILL.md` с YAML-frontmatter и непустыми строками `name`/`description`.
Поддерживаются BOM, LF/CRLF и многострочное описание. YAML использует core schema,
запрещает неизвестные теги и дубли ключей, ограничивает раскрытие aliases.
Дополнительные поля сохраняются, но не задают локальную версию.

Копируются исходные байты, скрытые/бинарные файлы, пустые каталоги и права файлов
`mode & 0o777`. Markdown и скрипты не переписываются. Внутренние/внешние symlink
разыменовываются; циклы, сломанные ссылки и специальные объекты отклоняются.
Лексический путь исходника сохраняется как identity.

Из обхода исключаются точные пути состояния CLI, общие установленные копии,
временная база и служебные work/lock-файлы, в том числе через symlink-алиасы.
Обычные ресурсы с похожими именами сохраняются. Источник `.` допустим.
Временная база должна существовать; адаптер создаёт внутри неё собственный workspace.

Размер папки не ограничен архивными лимитами. Копирование обнаруживает подмену конечного
файла и изменение размера, но не гарантирует атомарный снимок дерева при внешних правках.
AbortSignal пока не передаётся локальным адаптерам — см. R3 в [ревью](review-2026-10-13.md).

## Архивы

`SKILL.md` допускается в корне либо в единственной внешней папке, которая снимается
при подготовке. ZIP, произвольные URL, symlink/hardlink и специальные записи не поддерживаются.
Ссылка на сам локальный файл архива допустима; identity сохраняет путь ссылки.

| Ограничение                            | Значение |
| -------------------------------------- | -------- |
| Сжатый архив                           | 20 MiB   |
| Содержимое распакованных записей       | 25 MiB   |
| Записи файлов/каталогов                | 1000     |
| Полный tar-поток с заголовками/padding | 29 MiB   |
| Отдельная metadata-запись              | 1 MiB    |

Проверяются фактические байты и заголовки, эффективные PAX/GNU-пути, `..`, абсолютные
пути, дубликаты и конфликт файла с родительским каталогом. Нужны полный gzip,
512-байтные tar-блоки и конечные нулевые блоки; ненулевой хвост отклоняется.
Запись на диск начинается после проверки архива и остаётся внутри собственного workspace.

Registry-адаптер использует ту же подготовку архива и дополнительно сверяет имя
из SKILL.md со slug. `archiveHash` описывает архив, `contentHash` — распакованное дерево.
Подписанный URL не входит в постоянное состояние; подробности — в [Registry](registry.md).

Ошибки Sources: INVALID_SOURCE, INVALID_METADATA, SOURCE_CYCLE, UNSUPPORTED_ENTRY,
INVALID_ARCHIVE, ARCHIVE_LIMIT, PREPARATION_FAILED. При сбое очистки сохраняются путь
workspace и обе причины ошибки. Тесты адаптеров используют настоящие файлы и gzip/tar;
ошибки I/O вводятся через узкие `fileSystem`-интерфейсы.
