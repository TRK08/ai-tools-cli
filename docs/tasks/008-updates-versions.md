# 008. Обновление, версии и откат

## Цель и входные условия

После аппрува 007 реализовать update, политику latest/exact и явный откат через add. Использовать общую установку, не вызывать вложенный CLI. Правила — [SPEC.md](SPEC.md).

## Работы

1. Добавить `update [name]`, `-g`, повторяемый `-a`, `--force`. Без имени обрабатывать все подходящие установки; без `-a` использовать зарегистрированные подключения, без меню.
2. Для latest запросить текущий артефакт исходного registry из lock. Для exact пропустить обновление с объяснением; force не снимает фиксацию.
3. При совпадающих версии и хеше и отсутствии необходимости замены не скачивать архив и не менять файлы. Сравнение метаданных отделено от получения содержимого.
4. Для локальной папки/архива заново подготовить сохранённый источник и сравнить contentHash. Недоступный источник — ошибка без удаления установки.
5. Применять новую копию через существующее ядро с защитой правок, откатом и сохранением подключений. Перед заменой показать всех затрагиваемых агентов.
6. `update -a codex` фильтрует скиллы, но не изолирует версию от других агентов той же копии.
7. `add demo@1.1.0` выполняет явный откат и сохраняет exact. `add demo` снимает exact и выбирает текущую версию; одинаковое имя из другого источника остаётся конфликтом.
8. Пакетный update продолжает остальные записи после ошибок; итоговый код 1 при любом сбое. Показать результаты по скиллам: обновлён, без изменений, зафиксирован, ошибка.
9. Обновить README и Changeset. Операционные результаты должны позволять 010 отличить реальные изменения от повторов.

## Критерии готовности

- [ ] Latest обновляется из исходного registry; exact не обновляется обычным update или update --force.
- [ ] Явный откат и снятие фиксации выполняются через add.
- [ ] Неизменная установка не скачивается повторно без необходимости замены.
- [ ] Обновление локальных источников работает и сохраняет установку при отсутствии исходника.
- [ ] Общая версия обновляется для всех подключений, перечень затрагиваемых агентов виден пользователю.
- [ ] Ручные правки защищены без force; ошибка одного скилла не прерывает остальные.

## Проверки

- Общие проверки из индекса; latest → новая версия, exact → пропуск, явный downgrade, снятие фиксации.
- Сохранность всех подключений и исходного registry при смене окружения/registry по умолчанию.
- Проверить число HTTP-запросов/скачиваний при отсутствии изменений.
- Локальная папка и архив: изменённый источник, неизменный источник, исчезнувший источник.
- Ручные изменения установленного содержимого с/без force; force не обходит чужие ссылки и exact.
- Пакет из нескольких скиллов с одним сбоем: остальные обработаны, общий код 1.
- Фильтрация по агенту с общей копией и откат при сбое файловой операции.
