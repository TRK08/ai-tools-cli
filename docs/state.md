# Состояние установок

[StateStore](../src/state/store.ts) получает абсолютные cwd/home через `getStatePaths`.
Локальная область — точный cwd, глобальная — home. Локальная область в home и его
symlink-алиасе запрещена до чтения/изменения состояния.

| Область   | Общая копия                | Lock                                   |
| --------- | -------------------------- | -------------------------------------- |
| Проект    | `.agents/skills/<name>/`   | `./skills-installer-lock.json`         |
| Глобально | `~/.agents/skills/<name>/` | `~/.agents/skills-installer-lock.json` |

Vercel `skills-lock.json` независим. `package-lock.json` фиксирует зависимости npm и не относится к установкам скиллов.

## Схема версии 1

Lock содержит `version: 1` и словарь `skills`, ключ которого совпадает с `record.name`.
Описание типов — в [types.ts](../src/state/types.ts), строгая проверка — в [schema.ts](../src/state/schema.ts).

| Поле записи         | Значение                                                                      |
| ------------------- | ----------------------------------------------------------------------------- |
| `source`            | directory/archive с постоянным `path` либо registry с `registryUrl` и `slug`  |
| `version`, `policy` | Registry: фактический SemVer и latest/exact; локальные адаптеры: null и local |
| `contentHash`       | SHA-256 подготовленного дерева                                                |
| `archiveHash`       | Обязателен для archive/registry, отсутствует у directory                      |
| `agents`            | Непустой список зарегистрированных/желаемых агентов                           |
| `connections`       | Пары agent/path; схема допускает подмножество agents                          |

Неизвестные поля, агенты и версии схемы, неверные имена/хеши/политики и конфликтующие
пути отклоняются. Прямые агенты одной записи могут разделять её общий каталог.
Имя не содержит разделителей/управляющих символов, не равно `.`/`..` и занимает до 255 UTF-8 байт.

Проектные источники и подключения сохраняются относительно cwd; источник может быть
снаружи (`../source`), подключение — только внутри. Глобальные пути абсолютны.
Идентичность локального источника лексическая: symlink не меняет её на путь цели.
Registry-идентичность — base URL + slug, без версии и временного download URL.
Смена источника уже существующего имени требует remove/add.

## Чтение, запись и блокировка

- `read()` возвращает null только при отсутствии lock. Повреждённый JSON, symlink,
  специальный файл и неподдерживаемая схема дают ошибку.
- `transaction(callback)` удерживает `.skills-installer-operation.lock` рядом с lock;
  конкурентный писатель получает `SCOPE_BUSY`. Повторное использование завершённой транзакции запрещено.
- `write()`/`update()` валидируют и сортируют данные, записывают временный файл с `fsync`,
  затем заменяют lock через rename. Неуспешная запись удаляет временный файл.
- Оставшаяся после аварии блокировка не снимается автоматически. Блокировка State
  сама по себе не откатывает установки — это обязанность Installer/FileTransaction.

## Хеш содержимого

[hashDirectory](../src/state/hash.ts) учитывает относительные байтовые имена, типы
записей, содержимое файлов и признак executable. Поля имеют префиксы длины; обход
сортируется. Абсолютный путь, mtime, владельцы и остальные права не влияют на хеш.

Ссылки хешируются как ссылки без чтения целей; поэтому подмена установленного файла
ссылкой обнаруживается. Специальные объекты отклоняются. Файлы читаются блоками 64 KiB
с проверкой типа/inode и размера. Полной защиты от конкурентной подмены каталогов
сторонним процессом и атомарного snapshot дерева нет.

`hashDirectory(directory, options?)` принимает необязательные signal и узкий
fileSystem для тестов. Отмена проверяется между записями и блоками чтения,
дескриптор закрывается до выхода. Формат и значение хеша без отмены сохраняются.

Проверки: `state.test.ts`, `state-git.test.ts`, `content-hash.test.ts`.
Переносите через Git lock, копии и относительные ссылки вместе; служебные work/lock/tmp
исключайте, сохраняя ресурсы внутри скиллов.
