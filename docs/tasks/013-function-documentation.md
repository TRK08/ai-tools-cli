# 013. Мини-документация функций

## Цель и поручение

Часть согласованного плана пользователя 2026-10-13: «Для всех основных функций
во всех пакетах описать мини документацию над ними в формате TSDOC, либо просто текстом».
Порядок 010 → 012 → 013 → 011; начать только после аппрува результата 012.
Один npm-пакет; охват — модули src, а не соседние проекты.

## Работы

- Документировать экспортируемые функции, публичные методы и важные внутренние
  операции CLI, Installer, Sources, Registry, State, Telemetry, ошибок и отмены.
- Использовать русский текст в /** … */, совместимый с TSDoc; краткое назначение,
  при необходимости @param/@returns/@throws/@remarks.
- Пояснять существенные результаты, побочные эффекты, владельца очистки,
  блокировку, отмену и ошибки. Не повторять типы и строки реализации.
- Сохранить содержательные существующие пояснения и привести их к общему стилю.
- Обновить архитектурные документы: поток установки, добавление источника,
  агента и команды. Закрепить поддержку комментариев в AGENTS.md.
- Тестовые сценарии, одноразовые callbacks и простые внутренние обёртки без
  самостоятельного контракта не включать. Новых зависимостей и генератора не добавлять.

## Проверки и приёмка

Проверить охват по перечню экспортов и важных внутренних функций, соответствие
комментариев коду, форматирование, ссылки и согласованность документов.
Комментарии не требуют отдельных unit-тестов; семантические изменения не входят в задачу.
Результат передать в in_review, остановиться до аппрува. 011 автоматически не начинать.

## Результат для ревью

Добавлены/приведены к общему стилю русские комментарии /** … */ основных функций
CLI, Installer, Sources, Registry, State, Telemetry, агентов, ошибок и отмены.
По инвентаризации AST документированы **132 экспортируемые функции/публичных метода**
(включая конструкторы) и **51 внутренняя функция**. Сохранены содержательные пояснения
реализации 012. Изменены комментарии в 47 исходных файлах; всего проверен 51 файл src.

Пояснены специальный null/skipped/pinned, частичные результаты, версия артефакта,
тайм-ауты, отмена, lifetime сеанса State, владельцы cleanup и commit/rollback.
У параметров с неочевидным контрактом используются @param/@returns/@throws/@remarks.
Внутренние одноразовые callbacks и простые обёртки без самостоятельного контракта
не покрываются обязательным правилом; комментарии рядом с владельцем описывают их роль.

Обновлены architecture/installer/sources/state: порядок подготовки и применения,
добавление адаптера, агента и команды, границы I/O/lock, сохранённые пути и cleanup.
AGENTS.md закрепляет поддержку мини-документации при изменении функций.
