Новые подключения Codex, OpenCode, Cursor и Pi используют общую папку в обеих
областях. В интерактивном меню эти агенты закреплены; Claude Code выбирается вручную
через поиск. Поддержка прежних отдельных путей Pi/OpenCode/Cursor не предусмотрена.
Основной текст меню использует обычный цвет терминала; блоки отделены линиями,
заголовки и текущий пункт выделены точечно.
Карточка установки объединяет агентов с одинаковым путём в одну строку.
