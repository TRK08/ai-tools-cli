## Работы: статистика

1. Использовать существующий v1-envelope backend с уникальным eventId. Событие `install` не переименовывать в `add`.
2. Отправлять `download` после получения и проверки архива, `install` — по завершении операции со статусом success/partial/failed. Сохранять информацию об исходе даже при обрабатываемом исключении.
3. Контекст: операция add/update, область, агенты, версия когда уже определена. Одно событие установки на скилл и операцию, а не по одному на каждого агента.
4. Endpoint по умолчанию брать из исходного registry записи/операции: `/api/v1/skills/events`. Поддержать переопределение SKILLS_TELEMETRY_ENDPOINT.
5. Поддержать `--without-stat`, DISABLE_TELEMETRY и DO_NOT_TRACK. Для локальных источников, интерактивной отмены и повтора без изменений события установки не отправлять. При новом подключении событие установки отправляется.
6. Не считать получение подписанного URL скачиванием. При пропуске скачивания не отправлять download. Удаление накопительные счётчики не уменьшает.
7. Ограничить HTTP-отправку коротким тайм-аутом; ошибки не влияют на результат, откат и exit code. Не создавать постоянную очередь или файл событий.
8. Обновить README и Changeset. Изменения backend и публикация не входят в задачу.

### Контракт и поведение

Проверены текущий Swagger ai-tools-core (GET /api/v1/skills) и
`internal/service/skills/service.go` / `TestListSkillsSlugPrefix`.
API принимает **slugPrefix**: буквальный префикс slug с учётом регистра;
`%`/`_`/кавычки не имеют значения SQL wildcard. При отсутствии/пустом префиксе
API возвращает весь опубликованный каталог; find не запрашивает его при пустом поле.

`find [slug-prefix]` теперь использует именно этот API в обоих режимах.
Новый ввод отправляется через URLSearchParams после паузы **200 ms**; начальный
префикс и повтор Enter после ошибки запрашиваются сразу. Регистр и буквальные
символы сохраняются; слова не разбиваются, название/описание/теги не фильтруются.
Функция локального поиска удалена. CLI только валидирует и сортирует ответ
по числу установок и slug.

Новый префикс убирает прежние варианты из выбора, прерывает старый запрос и
повышает номер запроса. Ответ/ошибка с прежним номером игнорируются даже при
транспорте, не исполняющем abort. Пустое поле отменяет запрос и ждёт ввода.
Во время загрузки, ошибки или без совпадений скилл не выбирается. Ошибка API
показана отдельно; Enter повторяет запрос, редактирование меняет префикс.

Динамический renderer сохраняет оформление Clack, прокрутку, Unicode,
стрелки/Enter, Backspace/Delete, ←/→/Home/End, Ctrl+U и Escape/Ctrl+C.
Число строк ограничено размером терминала с отметкой `…`. Выбранная версия,
обычное меню агентов, -a/-g/force/without-stat и operation add сохранены.
Без TTY выполняется один запрос с slugPrefix и выводится таблица без установки.
Пустой префикс — ошибка с подсказкой; ошибка API — код 1, отсутствие совпадений — 0.
