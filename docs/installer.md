# Установка и подключения

[LocalInstaller](../src/installer/local.ts) координирует все три источника, несмотря на имя.
Внутренние методы: `add`, `addRegistry`, `update`, `list`, `remove`. CLI передаёт
область, агентов, подтверждения и Telemetry; прямой `add` по умолчанию выбирает Codex.

## Пути агентов

`<name>` добавляется к каждому каталогу из таблицы.

| Агент         | Проект            | Глобально                    |
| ------------- | ----------------- | ---------------------------- |
| `claude-code` | `.claude/skills/` | `~/.claude/skills/`          |
| `codex`       | `.agents/skills/` | `~/.agents/skills/`          |
| `opencode`    | `.agents/skills/` | `~/.config/opencode/skills/` |
| `pi`          | `.pi/skills/`     | `~/.pi/agent/skills/`        |
| `cursor`      | `.agents/skills/` | `~/.cursor/skills/`          |

Глобальный Claude учитывает `CLAUDE_CONFIG_DIR`, OpenCode — `XDG_CONFIG_HOME`.
Относительные env-пути разрешаются от cwd. Уже сохранённые подключения используют
пути из lock, даже после смены env. Перенаправленные через symlink родительские каталоги отклоняются.

Совпадающий с общей копией путь используется напрямую, остальные — через symlink;
в проекте ссылки относительные. Снятие прямого подключения из lock не скрывает
каталог от агента, пока остаются другие подключения.

## Add и update

StateStore блокирует область на всю операцию, включая подготовку и подтверждения;
пакетный update держит блокировку на весь пакет. Владение и хеш проверяются до
подготовки и перед заменой. `--force` разрешает заменить правки управляемой копии,
но не чужие назначения и не источник уже установленного имени.

Новые подключения объединяются со старыми. При частичном успехе сохраняются
успешные изменения, возвращается partial. Если все запрошенные подключения отказали,
прежняя копия и lock сохраняются. Одна новая общая версия используется всеми оставшимися агентами.

Registry-повтор с совпадающими версией, archiveHash и contentHash обходится без
скачивания. Чистый повтор не переписывает lock; смена только latest/exact меняет лишь lock.
Локальный источник готовится заново. Exact пропускается update без HTTP и проверки копии,
включая запуск с force. Агентский фильтр update выбирает записи, затем обновляет всех их агентов.

`reviewAdd(AddPreview)` и `reviewUpdate(UpdatePreview)` возвращают approve/decline/cancel.
Registry-версия фиксируется до подтверждения; локальный снимок используется однократно.
Отказ update пропускает запись, отмена останавливает пакет, ошибки отдельных записей
не мешают остальным. Уже применённые результаты сохраняются.

## Remove и list

List читает только собственный lock: без сканирования, сети или создания каталогов.
Фильтр агентов оставляет подходящие записи; таблица показывает всех агентов записи.

Remove снимает выбранные подключения; после последнего удаляет общую копию вместе
с ручными правками, без проверки хеша. Исходник остаётся. Чужие объекты не удаляются;
успешные удаления при ошибках других подключений сохраняются как partial.

CLI подтверждает общий список и передаёт в remove только показанных агентов, сохраняя
добавленных за время диалога. Remove использует текущую запись по имени, включая
заменённые за время диалога источник/версию: R1 принят пользователем как поведение.

## Транзакция и ограничения

`FileTransaction` хранит снимок, прежнюю копию и снятые ссылки в
`.agents/.skills-installer-work-*`. Rename и создание ссылок имеют обратные операции.
Сначала применяются файлы, затем записывается lock; после успеха или успешного отката
workspace удаляется. EXDEV завершает операцию с сохранением прежней установки.

Ошибка очистки после commit не откатывает записанное состояние. При неудачном откате
или очистке сообщение указывает оставшийся workspace. Пустые созданные родители могут остаться.
Crash journal отсутствует: после аварии возможны workspace и файл блокировки.
Перед ручным восстановлением нужно убедиться, что процесс завершён, и сверить lock с копией/backup.

Блокировка защищает от других писателей CLI, но не от сторонних редакторов.
До подтверждения add AbortSignal останавливает подготовку локальной папки/архива
и первоначальную проверку хеша установленной копии, в том числе с force.
Результат cancelled возвращается после закрытия ресурсов, очистки workspace и
освобождения блокировки; ошибки очистки не скрываются. После подтверждения
операция завершается транзакционно; отмена подготовки update не расширяется.
Контракты источников и состояния — в [Sources](sources.md) и [State](state.md).
