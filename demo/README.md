# Проверка demo

Из корня `ai-tools-cli` после `npm ci`:

```sh
npm run dev -- add ./demo -a codex
npm run dev -- list
node .agents/skills/demo/scripts/check.mjs
npm run dev -- remove demo
```

В меню области выберите текущий проект, затем подтвердите установку.
List покажет demo с локальной политикой и агентом codex; скрипт выведет `DEMO_SKILL_OK`.
После подтверждённого remove установленная копия исчезнет, исходная папка demo останется.
Для запуска без TTY добавьте `--yes` к add/remove.

Для проверки меню агентов запустите `npm run dev -- add ./demo` без `-a`.
Для защиты правок измените установленный `.agents/skills/demo/SKILL.md` и повторите add:
замена потребует `--force`. Сценарий создаёт реальные установки в текущем проекте;
автоматические тесты используют отдельные временные корни.

Глобальная область, версии и остальные команды описаны в [README](../README.md).
