The isolated runtime helper in scripts/isolated-runtime.mjs, used by
tests/helpers/test-environment.ts and package smoke, adapts
environment isolation from ../skills/src/test-utils.ts. The original license
notice is preserved below. No command handlers from that project are copied.
The slug and full SemVer patterns and registry reference parsing in
src/registry/reference.ts adapt ../skills/src/registry-source.ts under the same
license. The HTTP client and installer integration are implemented separately.
Install-count formatting in src/cli/find-ui.ts adapts ../skills/src/find.ts under
the same license. The asynchronous dynamic finder uses Clack styling and native keypress input;
the fork's search and command handlers are not copied.
